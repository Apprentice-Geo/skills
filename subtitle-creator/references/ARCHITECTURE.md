# 架构

## 职责和数据流

```text
本地音频 → open_subtitle_job → 按音频 SHA-256 定位 job
已完成 manifest → 公共 load_result() → bind_transcription
  → 本地不可变基准 + 可编辑工作副本
工作副本 → transcript show / edit / reset → generate_srt --format json|srt → JSON／SRT
```

- `open_subtitle_job.py` 按音频内容创建或恢复任务，返回当前可用产物；不生成字幕。
- `transcription_input.py` 通过公共 `load_result()` 只读接入上游，完整投影公开 `items` 字段；`bind_transcription.py` 验证音频身份并导入本地数据，每次显式绑定都替换基准、清空校正并使字幕失效。
- `subtitle_job.py` 验证任务身份、产物路径、文本校正边界、不可编辑 items、时间轴与字幕内容，发布本地工作副本。字幕导出、打开任务及有效性检查共用其渲染函数与 job 保存的配置；切分、校正回退及时间戳规则集中见[字幕渲染](SUBTITLE-RENDERING.md)。
- `transcript.py` 查看、批量修改文本，或从本地基准恢复文本；`generate_srt.py` 从合法工作副本直接生成所选 JSON／SRT 并记录校正 ID。
- `remove_subtitle_job.py` 只删除当前配置根目录下单个任务，拒绝链接与越界。
- `runtime_paths.py` 解析数据目录，`process_logging.py` 管理固定位置的会话日志。环境与依赖检查不参与字幕业务状态。

## 持久化和提交

任务只有 `transcription_unbound`、`transcription_bound` 两个状态。绑定后保存本地基准、工作副本路径、基准 digest、`changed_segment_ids` 和可空的字幕路径；生成后还保存 `subtitle_options`。后续编辑、reset、生成不读取上游或原音频，items 随本地基准保留。同一任务的命令必须串行执行。

只有绑定写入新基准；编辑和 reset 复用原基准路径及 digest。整批修改先校验，再在独立 `transcript-<random>/` 目录写工作副本，最后原子切换 job 引用，时间轴和 metadata 必须与基准一致。工作副本结构、数值类型和时间轴合法且文本无变化时，直接返回当前路径，不写 job、不使字幕失效；全部 reset 遇到损坏副本时从可信基准重建。文本改变或副本重建时重新计算校正 ID 并将字幕声明置空；旧字幕可以残留，不能作为有效字幕交付。

写入或校验失败时清理候选文件，旧状态保持可用；提交异常可能发生在原子替换后，工具重新读取磁盘声明确认当前引用。确认新声明时清理旧工作副本，确认旧声明时清理候选文件，无法确认则保留两份并警告。异常仍抛出，恢复依据是磁盘 job，不是命令是否报错。正常提交后也只清理已替换的受管文件，保留仍被引用的基准和用户附加内容；不维护编辑历史。

受管文件清理仅限本任务直接子目录 `transcript-<32位小写十六进制>/` 内的转写文件及空目录，拒绝 symlink、junction 和越界路径。清理失败只警告，不回滚已提交任务。残留目录不是恢复依据，随整个任务删除。

打开、查看、编辑和单段 reset 要求基准与工作副本结构、时间轴合法，允许校正记录或字幕陈旧；查看、编辑和 reset 不读取或重建旧字幕。全部 reset 只要求任务声明及基准可信，能修复缺失或损坏的工作副本。重新绑定只要求任务声明可信及新转写有效。打开与生成命令复用本次已验证的基准与工作副本；打开任务只检查一次字幕是否与当前工作副本预期字节一致，一致时才返回其路径。生成验证时间轴与文本，渲染一次并核对写入字节，再更新校正记录与任务声明。

## 持久化结构

本地 job、转写基准和工作副本不设独立版本号，只接受当前精确字段结构，不迁移历史格式。包含旧 `schema_version`、缺少字段或损坏 items 的数据均拒绝，保留原文件；任务包含人工校正，不作为缓存自动删除或重建。job 必须包含可空的 `subtitle_options`；声明字幕时必须保存生成参数。转写必须包含不可编辑且完整保留公开字段的非空 `items`；合法但不能对应的 items 按段回退。上游公共转写仍通过 `audio-transcribe-contract` 验证，不受本地结构简化影响。

已验证 transcript 使用递归 JSON 序列化，有限 `Decimal` 直接写成 JSON 数字，保留 duration 和时间戳精度，不经 `float`。基准与工作副本允许位于不同目录。

`artifacts.subtitle` 保存当前交付字幕的路径，扩展名决定 JSON 或 SRT；生成与恢复共用同一断句结果及对应序列化，不强制同时生成两种文件。新参数不含阅读尾部设置；旧任务的 `tail_factor=1.1` 可读取，重生成时移除，旧延长产物按陈旧字幕处理。
