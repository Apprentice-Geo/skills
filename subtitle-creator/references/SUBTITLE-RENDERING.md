# 字幕渲染

## 切分与文字归属

生成 JSON／SRT 不修改本地基准、工作副本、原分段 ID 或校正单位。仅在每个原段内部按 items 原顺序累积，不跨段合并，不在单个 item 内推测切点，不额外运行模型。

默认字数软目标为 24 个非空白 Unicode 码点，包含标点；默认时长软目标为 6 秒，最小停顿为 0.2 秒。当前字幕达到任一目标后，在第一个满足 `next.start - current.end >= min_gap` 的边界切分；达到阈值前的停顿不作为切点。没有合格停顿或单个 item 过长时允许超过目标，末尾不足目标的内容保留。切点不保证语言学上的词语完整。

items 先按完整时间包含关系归属原段。再去除空白和 Unicode 标点，核对 item 文本能否按顺序完整对应原段文本。跨段、归属歧义、缺少 item、文字不匹配或无实字 item 无法提供唯一锚点时，受影响段不细分；生成时警告段 ID，不猜测时间。

文字先沿用现有 SRT 空白规范化：连续空白折叠为一个空格，去掉首尾空白。切分按原文位置截取，边界间标点归前一条，各条去掉首尾空白，不增加段内换行。第一条开始和最后一条结束沿用原段边界；内部边界分别取前后 item 的结束与开始时间。

## 校正后的切分条件

基准 items 不随校正改变。校正前后均执行上述空白规范化；只有文本等长，且每个标点、空白的位置与字符完全一致时，才允许其他字符逐位置替换并沿用基准切点。增删字符、改变标点或空白位置时，整个校正段保持原分段，不尝试重新对齐。

## 时间戳与毫秒

导出保留原始分段或细分后的开始、结束时间，不增加阅读尾部。阅读延长、与画面同步及已知编辑后的时间映射由视频项目处理。转写时间戳是制作定位依据，不承诺声学边界完全精确。

使用 Decimal 和毫秒 `ROUND_HALF_UP` 取整。新切分产生取整后零时长块时，撤销相应切点，优先并入前块；首块则并入后块。只在同一原段内撤销切点。原段本身无法合法输出时仍报错。

JSON 与 SRT 复用同一份最终断句结果。JSON 为 UTF-8，格式如下，`id` 为本次结果中从 `"1"` 开始的字符串序号，时间使用整数毫秒：

```json
{
  "version": 1,
  "cues": [{ "id": "1", "text": "示例字幕。", "startMs": 0, "endMs": 1200 }]
}
```

JSON 是字幕交付物，不是可校正的转写工作副本。项目可以直接消费、复制并按已知编辑映射字幕；修改项目副本不回写 Skill 任务。

## 渲染配置

job 的 `subtitle_options` 保存当前生成实际使用的 `target_chars`、`target_seconds`、`min_gap`；生成后的编辑、reset 和重新绑定保留参数，字幕声明按原有规则失效。首次生成使用默认值，后续未显式指定的阈值复用记录值。参数约束和命令见[生成参数](OPERATIONS.md#生成参数)。

导出、打开任务和字幕有效性检查共用相同渲染函数、基准及配置。首次生成前 `subtitle_options` 可为空；声明字幕时必须保存生成参数，按当前切分及未延长时间戳规则验证。持久化结构见[架构](ARCHITECTURE.md#持久化结构)。

旧任务保存的 `tail_factor=1.1` 仅用于读取兼容，生成时移除并停止应用；基准、校正与切分参数继续复用。旧延长字幕可能被判为陈旧，重新生成即可，不需重绑或重转写。
